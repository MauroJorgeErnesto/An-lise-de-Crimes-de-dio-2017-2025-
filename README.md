Este projeto realiza uma análise exploratória e preditiva de dados de crimes de ódio registrados entre 2017 e 2025, 
com o objetivo de identificar padrões temporais, geográficos e comportamentais. Utilizando Python e bibliotecas como pandas, matplotlib, seaborn e scikit-learn, o projeto inclui:

Limpeza e pré-processamento de dados (remoção de anos duplicados, tratamento de valores ausentes).

Análise temporal (tendências anuais, sazonalidade, dia da semana).

Análise de vítimas e ofensores (distribuição por idade, raça/etnia).

Agrupamento de crimes (análise de co-ocorrência, clustering hierárquico, regras de associação).

Visualizações interativas (mapas de calor, dendrogramas, redes de associação).

📊 Resultados Esperados
✅ Padrões temporais (ex.: aumento de crimes em certos meses).
✅ Grupos de crimes que costumam ocorrer juntos.
✅ Perfil de ofensores mais comuns.
✅ Visualizações interativas para melhor interpretação.
